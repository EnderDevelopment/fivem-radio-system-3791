# FiveM Radio System

A versatile radio system for FiveM servers with multiple channels and configurable settings.

## Features

- Multiple radio channels with configurable frequencies
- Configurable radio volume and range settings
- Player-specific channel management

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files.
2. Place the files in your FiveM server's resources directory.
3. Add `start radio_system` to your server.cfg file.
4. Import the database.sql file into your MySQL database.

## Usage

- Players can join radio channels using the `/radio` command.
- The radio system supports configurable volume and range settings.

## Configuration

The script includes a `config.lua` file where you can configure:

- Default radio channels
- Maximum number of radio channels a player can have
- Radio volume settings
- Radio range
